# AGENTS.md

A self-study library: 17 guides on Temporal Cloud's cell infrastructure and the open-source
tools underneath, plus a flashcard drill deck. Written before joining, from public sources only.

## Layout

- `guides/*.md` — source of truth. Edit these, never `html/` by hand.
- `build.py` — renders `guides/` into `html/*.html` and `index.html`; card labels/tags live in `META`.
- `drill.html` — hand-written flashcard deck; not generated by `build.py`.
- `style.css` / `html/style.css` — generated by `build.py`.

## Building

```bash
uv run --with markdown --with pygments==2.11.2 python build.py
```

Keep Pygments pinned to 2.11.2. Newer versions rewrite every code block's markup and the CSS,
producing thousands of lines of noise in the diff.

## Content rules

- **No internal information.** Facts about Temporal Cloud must come from Temporal's public docs,
  blog, or open-source code, linked inline. Anything beyond that is labeled *inference* or
  *industry pattern*.
- **Keep it general.** Don't name any specific team or job level, don't quote job postings or
  hiring conversations, and frame guides as general cell-infrastructure
  ramp-up material. Mentioning Temporal is fine.
- **Example names use `example.com` / `example.internal`**, never Temporal's real domains.
- Every guide opens with a `**Why this matters.**` paragraph (`build.py` styles it and uses it for
  the index card excerpt) and ends with a numbered `## References` list.
- The disclaimer lives in `README.md` and `DISCLAIMER_HTML` in `build.py`, which prints it on the
  index and at the foot of every guide page.

## Behavior to preserve

Every page carries a small script that opens external `http(s)` links in a new tab while links
inside the library (sidebar, cards, search hits, drill deck) stay in the same tab. It is injected
by `page()` in `build.py` and copied by hand into `drill.html`; change both together.
